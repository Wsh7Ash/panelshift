# Changelog

## 0.1.0 — 2026-11-24

- Initial release.
- Exact subset-sum DP for single-phase 120/240 V panel balancing.
- Two-pole and shared-neutral (multi-wire branch circuit) constraints.
- 125 % continuous-load handling in integer centiamps.
- Infeasibility diagnosis with best achievable leg load and slot arithmetic.
- Two-column slot layout, text and JSON reports, certificate metadata.
- Independent `verify` command.
- 43 unit tests including a brute-force optimality oracle, plus a demo gate.
